# Prism Pass 交接说明

用浏览器打开 `index.html`：切换外观、选择通行证、再次切换外观、取消选择。没有构建步骤、CDN、外部字体、存储或服务器依赖。

`index.html` 是源码；`reference.svg` 是原创参考。CSS 渐变属于实现选择，不是对原作者技术的还原结论。`design-tokens.json` 记录实际使用的参数。

页面在 `document` 上发送 `pass-change` 自定义事件，`detail` 为 `{finish, selected}`。接入应用可以监听该事件，再按自身接口保存；Demo 只保留内存状态，刷新后重置。

| 操作或状态 | 预期结果 |
|---|---|
| 初始 | 蓝色，未选择 |
| 选紫色 | 变为紫色，选中状态不变 |
| 选择 | 本地选中提示，选择按钮暂时禁用 |
| 选中后切换外观 | 状态文字同步更新，发出一次事件 |
| 取消 | 清除选中状态，保留外观，焦点回到选择按钮 |
| 键盘 | 原生单选框及按钮支持相应方向键、空格、回车和焦点移动 |
| 指针移动 | 装饰性倾斜，最大六度 |
| 减少动态效果 | 无倾斜或过渡，选择及取消仍可用 |
| 刷新 | 恢复蓝色、未选择 |

这是组件示例，不是完整产品。上表是预期行为；实际检查范围见审阅目录的验证记录。
