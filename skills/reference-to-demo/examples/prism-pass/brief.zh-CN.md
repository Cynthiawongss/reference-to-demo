# Prism Pass · 原创设计案例

## 输入需求

为虚构设计展制作一张可选择的通行证。使用附带的原创 `reference.svg` 作为参考，保留斜向光带，同时保证手机上的文字可读和操作可用。提供两种外观及可取消的本地选择；不需要账号、结账、存储或网络请求。

| 类型 | 参考依据 | 实现取舍 |
|---|---|---|
| 观察 | SVG 中部斜向光带 | 保留这个视觉特征 |
| 观察 | 大标题与底部编号 | 保留两级文字关系 |
| 推测 | 静态 SVG 没有动作信息 | 指针倾斜是可选的新实现，不声称原作有这个效果 |
| 适配 | 参考只有蓝色 | 增加紫色选项 |
| 适配 | 原文字属于 SVG 图形 | 用 HTML 文字重建 |
| 适配 | 参考没有操作控件 | 在旁边增加外观、选择、取消与状态反馈 |

## 预期结果

两种外观切换不丢失选择状态；键盘和触屏均能选择或取消，焦点可见。明确说明状态仅在本地，刷新后重置。减少动态效果设置禁用倾斜，但不取消任何功能。素材应可离线使用。
